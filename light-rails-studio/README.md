# Light Rails Studio — personal reconstruction

This branch is a personal study reconstruction of the interaction shown in the user's Light Rails reference video.

## Functional reference
The rendering/parameter architecture was informed by the public `msriaj/pattern-forge` project, which describes itself as inspired by Light Stroke Rail. This reconstruction changes the shell, workflow, copy, preset handling, history controls and bilingual localization to match the supplied reference more closely.

## Rendering credits inherited from the reference architecture
Several experimental GPU templates in the rendering layer are adapted from Shadertoy works credited by Pattern Forge, including works by Leon Denise, Hadyn, muragustina, ChunderFPV, mrange, xinchenl, Reva, Peace, nimitz and Danil/arugl. The `ether` shader is noted there as CC BY-NC-SA 3.0 and should not be used commercially without appropriate licensing.

This project is intended for personal study/use.
